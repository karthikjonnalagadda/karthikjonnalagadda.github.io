Flagship2026

Medical Multimodal AI Assistant

A clinical decision-support system that reads lab reports with OCR, analyses chest X-rays with a CNN, and answers questions through a retrieval-augmented LLM — grounded in retrieved evidence rather than model memory.

  • 10 REST endpoints
  • 50/50 tests passing
  • 60% coverage
  • 4 LLM backends
  • Python
  • FastAPI
  • PyTorch
  • Sentence Transformers
  • ChromaDB
  • FAISS
  • LangChain
  • EasyOCR
  • Tesseract
  • MongoDB
  • React
  • Streamlit
Source ↗

Architecture

  • FastAPI service exposing OCR, image analysis, multimodal diagnosis, chat and knowledge-ingestion endpoints.
  • Three delivery surfaces over one backend: React + TypeScript dashboard, Streamlit research UI, REST API.
  • Hybrid retrieval — dense Sentence-Transformer embeddings plus lexical scoring over ChromaDB/FAISS.
  • Lazy model initialisation keeps weight loading off the request path.

Engineering challenges

  • Schema-contract defect: prompts asked for markdown while the LLM wrapper enforced JSON response mode, so parsing failed intermittently. Fixed with a strict schema plus a normalisation layer, locked by regression tests.
  • Duplicate embeddings: re-ingestion wrote the same chunks repeatedly. Made chunk IDs content-hash deterministic so ingestion is idempotent.
  • Missing weights crashed startup: replaced with a 3-backend vision registry that degrades gracefully instead of failing.

Engineering decisions

  • Provider-agnostic LLM layer across Groq, OpenAI, xAI and local BioGPT — swap models by config, not code.
  • Explainability is not optional: Grad-CAM, SHAP and LIME ship with every prediction.
  • Dependencies split into a minimal runtime set and a development set to cut install surface.
Full-stack ML2025

SafeInbox — Real-Time Spam Detection

A live-inbox spam classifier: scikit-learn model served into a Node/Express runtime, reading real mail over the Gmail API and IMAP.

  • 26,972 training emails
  • 1.03M TF-IDF features
  • 2 ingestion paths
  • Python
  • Scikit-learn
  • TF-IDF
  • Node.js
  • Express
  • React
  • MongoDB
  • Docker
  • Jenkins
Source ↗

Architecture

  • Multinomial Naive Bayes over a 1,034,706-feature TF-IDF space (1–3 grams, English stop words).
  • Node/Express backend invokes Python inference directly — no separate model-serving service to operate.
  • Dual ingestion: Gmail API with OAuth2, and IMAP with MIME parsing.

Engineering decisions

  • Trained on the Enron corpus (13,263 ham / 13,709 spam) — a near-balanced split, so accuracy is a meaningful headline metric.
  • Model and vectoriser persisted as artifacts so inference never retrains.
  • JWT auth, bcrypt hashing and route guards on both API and client; Docker image with a Jenkins pipeline.
Unsupervised ML2025

Genomic Dimensionality Reduction & Clustering

Benchmarked two dimensionality-reduction strategies on high-dimensional genomic data and chose between them on measured cluster agreement rather than intuition.

  • 0.66 ARI (SVD)
  • 0.56 ARI (NMF)
  • Python
  • Scikit-learn
  • Pandas
  • NumPy
  • Matplotlib
  • Seaborn

Method

  • SVD and NMF compared ahead of K-Means; SVD selected on Adjusted Rand Index (0.66 vs 0.56).
  • Random Forest trained on the reduced feature space to validate separability independently of the clustering objective.
  • EDA — variable gene identification, correlation heatmaps, top-gene plots — to interpret clusters biologically.
